# Notebooks

Use this directory for Drake tutorials, MIT Robotic Manipulation exercises, and
small explorations of frames, model loading, Meshcat, and inverse kinematics.

Record the source URL and revision/date for adapted examples, and respect their
licenses. Note any additional dependencies before adding them to the environment.
Use the environment installed with `.[dev,notebooks]` as the notebook kernel.

Restart the kernel and run all cells before relying on a result. Promote reusable
code to `src/embodied_tamp/` when needed; the final comparison should also be runnable
as a script. No notebooks are implemented yet.
