# Notes

Keep learning logs, environment setup notes, design decisions, and short experiment
reports here. Date entries and distinguish observations from hypotheses and plans.

For the baseline environment, record OS/architecture, Python and dependency
versions, and setup commands. For results, include the git revision, model and task
inputs, reproduction command, numerical evidence, and limitations.

The current environment and next setup checks are recorded in
[Guix development](guix-development.md).

Open decisions are the robot pair, precise target constraints, and the tested
environment to pin. The README's `reach(target)` example is a proposal only.

Place ideas about learned predicates, operator learning, and ROS 2 in
`FUTURE_WORK.md` so learning notes do not quietly become implementation commitments.
